## 二、作品是什么
**QYNote Compilation** 是一个**纯本地**的 Obsidian 整理插件，附带一个可在线操作的交互演示和一套本地 MCP 工具面。它只做一件事并把闭环做透：**循证整理笔记**。
- **循证双链推荐**：为当前笔记推荐可关联笔记，展示"相关依据词"与目标摘录，不是凭空连线。
- **整库整理计划**：扫描全库生成"每个文件至多改一处"的计划——合并高相似重复、标注观点矛盾、补高置信双链；可逐项预览后批量应用，也可一键应用。
- **安全写回**：所有修改先 Diff 预览 → 人工确认 → 仅追加写回（不改原文、不删除）→ 可一键撤销；计划生成后文件若被改动则整批取消。
- **纯本地、零联网、零模型、零密钥**：中文分词 + TF‑IDF 全在本机跑，不上传任何笔记。

## 三、为什么做
- **记下来 ≠ 理清**：笔记收藏后散落各处，缺少整理，知识变孤岛。
- **链接靠手动**：相关笔记之间没有双链，人力补不全、补不准。
- **整库难理顺**：重复、矛盾的笔记散落全库，逐篇人工核对成本太高。
- 我用 Qoder 实测了多个往届 StudyHack / LifeHack / Hack4Good 作品，发现"功能堆很多但三分钟讲不清核心"是通病。因此我刻意**只做整理**、把"证据 → 预览 → 确认 → 撤销"闭环做扎实；不用大模型语义判断，保证每条建议可核查、隐私可控。

## 四、怎么用（5 步）
1. **安装启用**：下载 [安装包](https://github.com/hqy2026/qynote-compilation/releases/download/v1.2.0/qynote-compilation.zip)，解压到 `你的库/.obsidian/plugins/qynote-compilation/`；Obsidian 设置 → 社区插件 → 关受限模式 → 启用 QYNote Compilation。
2. **打开侧边栏**：点左侧 ribbon 网络图标（或命令面板"打开知识库概览"），看到「整理 / 计划」两个入口。
3. **整理当前笔记**：在「整理」页查看带证据的双链推荐 → 点"预览并添加"看 Diff → 确认写回。
4. **整库一键理顺**：在「计划」页点"生成整库计划" → 逐项预览后批量应用，或"一键应用全部"；仅追加、每文件至多一处。
5. **随时反悔**：任何写回后点"撤销上次整理"，整体恢复写回前内容。

不想安装也能体验第 3–5 步：直接打开[在线演示](https://vaultcoach-lp9v9mm3elt.qoder.zone)（内置样例库，含整理/计划双页）。

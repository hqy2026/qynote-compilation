# 【StudyHack】QYNote Compilation：让 Obsidian 笔记循证自整理的本地插件

> 一句话：不靠大模型、不联网，用本地词形相似度 + TF‑IDF 为 Obsidian 笔记循证补双链、诊断重复与矛盾、生成整库整理计划；所有写回先预览、确认后仅追加、可一键撤销。

## 1. 解决的痛点
- **记下来 ≠ 理清**：笔记收藏后散落各处，缺少整理。
- **链接靠手动**：相关笔记之间没有双链，知识是孤岛，人力补不全。
- **整库难理顺**：重复、矛盾的笔记散落全库，逐篇人工核对成本太高。

## 2. 核心功能（仅整理，闭环清晰）
- **循证双链推荐**：为当前笔记推荐可关联笔记，展示"相关依据词"与目标摘录；Diff 预览 → 确认 → 仅追加写回 → 可撤销。
- **知识诊断**：近似重复、相互矛盾（含否定对）、缺来源观点句，每条附证据与行号，作为整理候选。
- **整库整理计划**：扫描全库生成"每个文件至多改一处"的计划（合并重复 / 标注矛盾 / 补双链），逐项带 Diff 审阅后批量应用，也可一键应用，整体可撤销。
- **安全写回模型**：预览 → 确认 → 原子写入 → 校验（计划生成后文件被改则整批取消）→ 只追加不改原文 → 可撤销。

## 4. 安装与版本
- 插件 id `qynote-compilation`，版本 **1.2.0**，minAppVersion 1.14.4。
- 安装包公开下载：<https://vaultcoach-lp9v9mm3elt.qoder.zone/download/qynote-compilation.zip>（v1.2.0，约 14KB）。解压到 `你的库/.obsidian/plugins/qynote-compilation/`，设置 → 社区插件 → 关受限模式 → 启用。
- 或源码 `npm install && npm run build`，复制 manifest.json / main.js / styles.css。

## 5. 用 Qoder 完成的开发与验证过程（真实）
1. 用 Qoder 实测对比多个 StudyHack / LifeHack / Hack4Good 作品，确立"功能多≠好"，选定 Obsidian 循证整理方向。

## 6. 效果与数据（本轮实测）
- 推荐质量（50 例受控评测）：Top1 准确率 **96%**、Top3 召回 **100%**、负样本误报 **0%**。
- 自动化：34 项 Vitest（含 jsdom 演示交互）+ MCP 冒烟/原子性故障注入/自包含单文件隔离自检 全绿。
- 真实 Obsidian 端到端：加载/诊断/双链写回撤销/整库计划逐项与一键应用/大库性能 全通过，runtimeErrors 0。
- 另提供本地 MCP 工具面（9 个只读/预览/受闸门写入工具），与插件共用同一计划构建器，供 agent 以同样安全约束整理。

## 7. 隐私与诚实边界
- 全程本地计算，不联网、不上传笔记，无账号与密钥。
- 推荐基于本地词形相似度 + TF‑IDF，**不是大模型语义判断**；重复/矛盾仅作人工核对候选，确认后才写回且可撤销。
- 在线演示使用内置样例库，不代表任何真实用户内容。
